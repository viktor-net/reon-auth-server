ИС РЕОН 2.0 — DEV-стенд аутентификации

Точка входа nginx — прокси к Keycloak; наружу опубликованы IdP и документация.

Зачем нужен nginx

nginx существует только как точка входа: он проксирует к Keycloak три префикса и публикует всё на одном адресе http://localhost:10010.

ПутьЗачемКто отвечает
/realms/OIDC: discovery, token, userinfo, jwksKeycloak (OIDC)
/admin/Admin REST API и консольKeycloak
/resources/
служебный префикс темы входа, индексной страницы нет		статика страницы входаKeycloak
/docs/Scalar-документация APIScalar, не Keycloak
/healthzhealthcheck composeсам nginx, не проксируется
/эта страница-указательсам nginx

http://localhost:10009 — прямой доступ к Keycloak без прокси (консоль администратора, отладка). Автоматического редиректа между 10009 и 10010 нет: порты независимы, редирект не настраивается.

Что nginx не проксирует

Всё вне этих префиксов получает 404 от самого nginx: до Keycloak и Scalar запрос не доходит. Проверено на стенде:

  • /welcome, /welcome-content/, /js/ — старая тема админки;
  • /robots.txt, /favicon.ico, /metrics — таких файлов нет;
  • любой произвольный путь, например /nonexistent.

Одиночный /.well-known/ не проксируется: discovery есть только у realm — /realms/reon/.well-known/openid-configuration.

Management-порт Keycloak 9000 (health, metrics) не публикуется ни nginx, ни compose: только внутри контейнера.

localhost:10008 — Postgres, отдельный сервис стенда, к nginx отношения не имеет.

Консоль администратора при этом работает: /admin/master/console/ — 200.

Адреса стенда

  • Issuer: http://localhost:10010/realms/reon — 200, JSON OpenID-конфигурации realm.
  • Discovery: /realms/reon/.well-known/openid-configuration — 200, JSON.
  • Форма входа: /realms/reon/account/ — 200, HTML (консоль аккаунта).
  • Admin REST API: /admin/realms/reon — без токена отвечает 401 JSON, это норма: эндпоинт требует Bearer-токен администратора.
  • Консоль: http://localhost:10009/admin/ — открывает консоль Keycloak; форма входа уходит на 10010, потому что issuer задан через KC_HOSTNAME. Это штатно.

Администратор консоли Keycloak (master realm) — admin / пароль из .env (по умолчанию dev-admin-change-me); пользователи realm reon (dev-*, syn-*) в консоль Keycloak не входят — они входят на форме reon / в консоли аккаунта.
